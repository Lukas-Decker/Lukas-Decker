# Hi, I'm Lukas

Junior software developer from Germany, currently completing my apprenticeship as a
Fachinformatiker für Anwendungsentwicklung. By day I build and maintain productive
enterprise software in an agile team; by night I take games and websites apart to see
how they work, then build tools around what I find.

## What I build

- **Hunt: Showdown 1896 toolchain** - my biggest project: a Python pipeline that
  extracts data, models and textures straight from the game install and feeds a
  whole family of tools. The centerpiece is a wiki built on a self-written modular
  vanilla-JS framework (17 independent modules, no build step, no runtime
  dependencies), live at [wiki.huntify.win](https://wiki.huntify.win). Around it:
  an interactive map, a browser-based 3D model viewer, a Godot scene studio and a
  read-only local stats API.
- **Cuckoo** - a native Windows desktop app (C# / WPF) that mines timed Twitch drops
  by talking to Twitch's GraphQL and PubSub endpoints directly, with multi-account
  support, a compact widget mode and push notifications.
- **AccountSwitcherGO** - a fast account switcher for Steam, Battle.net, Epic Games
  and other launchers, rebuilt from the ground up in Go with a Svelte/TypeScript
  frontend.
- **ZuhausApp** - an offline-first household app (Flutter) for Android and desktop:
  inventory with barcode scanning, shopping lists, notes, medication and pet
  trackers, with optional end-to-end sync via Supabase.
- Plus a drawer full of smaller things: Discord and Telegram bots, userscripts,
  scrapers, data-aggregation and analysis tools, and various quality-of-life
  utilities for games and websites.
