# Hi, I'm Lukas

Junior software developer from Germany. I'm finishing my apprenticeship as a Fachinformatiker (application development) at GUBSE AG, where I work on productive enterprise software: feature development, bug fixing, Jenkins CI/CD pipelines and Scrum-based teamwork.

## What I build in my spare time

- **[hunt-showdown-wiki](https://github.com/Lukas-Decker/hunt-showdown-wiki)** - wiki for Hunt: Showdown 1896 on a self-built modular vanilla-JS framework (17 independent modules, no build step, no runtime dependencies), fed by a Python data pipeline that derives everything from the game install
- **[Cuckoo](https://github.com/Lukas-Decker/Cuckoo)** - native Windows desktop app (C# / WPF) that AFK-mines timed Twitch drops via Twitch's GraphQL and PubSub endpoints, with multi-account support and a compact widget mode
- **[AccountSwitcherGO](https://github.com/Lukas-Decker/AccountSwitcherGO)** - fast account switcher for Steam, Battle.net, Epic and more, built with Go and a Svelte/TypeScript frontend
- **[ZuhausApp](https://github.com/Lukas-Decker/ZuhausApp)** - offline-first household app (Flutter) for Android and desktop with optional Supabase sync
- **[HuntMap](https://github.com/Lukas-Decker/HuntMap)** and **[HuntAPI](https://github.com/Lukas-Decker/HuntAPI)** - interactive map recreation and a read-only local stats API for Hunt: Showdown 1896
